# Future EMA: offline fault injection runner

Дата: 2026-10-03. Тесты: локальный commit `e6d18aa`.

## Результат этапа

Добавлен самостоятельный bounded unittest-файл `tests/test_genetic_primus_future_ema_runner_v1.py`. Все **10 тестов прошли**, время тестового набора **0,067 s**. Предварительный `py_compile` этого файла также успешен.

Использованы временные каталоги и искусственные данные. Загрузка parquet, исторического snapshot, git-проверка manifest и evaluator подменены заглушками там, где они не являются предметом теста. Производственные функции сохранены для адресных проверок записи, сравнения git bytes и изменения SHA во время чтения. Рыночные данные и торговая доходность не вычислялись. Время завершённого окна подставляется только в unittest; у production CLI нет override времени.

## Проверенные отказы и границы

1. Фиксация manifest не запускает evaluator; повторная фиксация отклоняется.
2. Несовпадение objective в manifest отклоняется до чтения рынка.
3. Подмена SHA, размера или канонических строк сегмента не достигает evaluator и не создаёт reservation.
4. Reservation существует до начала расчёта; успешный анализ не допускает повторного запуска.
5. Ошибка расчёта сохраняет reservation и диагностический файл; повторный запуск отклоняется.
6. NaN в результате отклоняется сериализатором до создания result.json; reservation сохраняется.
7. Коллизия exclusive reservation между предварительной проверкой и записью блокирует расчёт. Это последовательная fault injection, не многопроцессный нагрузочный тест.
8. Git bytes manifest должны совпадать точно; изменённые bytes отклоняются.
9. Exclusive writer не перезаписывает существующий файл и не создаёт файл с Inf.
10. Изменение SHA во время чтения сегмента и путь вне workspace отклоняются.

## Что осталось неизменным

Все шесть SHA зарегистрированной реализации сверены с lock и совпали. Контракт, fitness/gates, период, frozen evaluator и runner не изменялись. Новых гипотез, genomes, fits, real PnL и результатов future-оценки нет. GA и promotion остаются запрещены. Сеть, collector, pytest, paper/live и trading runtime не запускались.

Текущее окружение: Python 3.12.4; numpy 2.4.2; pandas 3.0.0; pyarrow 25.0.0. Это диагностическая фиксация версий, не полная переносимая среда и не дополнительный обязательный environment gate.

## Непроверенные ограничения

Тесты подтверждают Python-level control flow, но не устойчивость к внезапному отключению питания, потере дискового кеша, повреждению файловой системы или принудительному завершению процесса. Exclusive create предотвращает конкурирующий расчёт в проверенном сценарии, но не является доказательством физической долговечности записи. Повреждённый reservation/result требует ручного разбора; удалять их для автоматического повторного анализа нельзя.

Этот этап не проверяет реальные fills, funding, рыночную прибыльность и глобальные DSR/PBO. Он не меняет решение NoTrade и не приближает допуск к деньгам без статистического и execution evidence.

## Следующая работа

До завершения future interval можно подготовить воспроизводимую offline-среду и процедуру ручного разбора повреждённых артефактов. Не повторять эти же проверки без изменения кода и не открывать промежуточные PnL ради настройки. Единственный статистический анализ полного окна остаётся не ранее **2027-04-03 00:00 UTC**, после фиксации полного сегмента и commit его manifest. Автоматического запуска нет.
