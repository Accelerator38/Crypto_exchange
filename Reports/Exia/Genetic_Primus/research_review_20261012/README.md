# Genetic Primus исследовательский срез 12 октября 2026

Это отдельная публикация исследований, не разрешение на реальные торги. Архивный README репозитория не описывает наличие этих новых offline checkpoints.

1. [Текущее состояние системы](REPORT_1_CURRENT_STATE_RU.md) — архитектура, данные, история гипотез, сравнения, ограничения и выбор кандидатов.
2. [Пути улучшения и литературный обзор](REPORT_2_IMPROVEMENT_RESEARCH_RU.md) — первичные научные источники, новая программа экспериментов и критерии продолжения.
3. [Переносимый модельный пакет](model_bundle/README.md) — EMA_V/Passive_V baselines, Huber_H3 candidate и Ridge_C reference.

Проверено 800 hashes пяти цепочек; 3 097 проверок переноса и 9 самостоятельных bundle checks. Новое обучение и новый финансовый replay не выполнялись. Графики построены из сохранённых ledger; проверены визуально. Значения последних fits относятся к 30 сентября, не являются сигналами на текущую дату.

`release_manifest.json` фиксирует байты публикации. `evidence.json` содержит основные численные основания и provenance; `chart_data.json` — точки для опубликованного графика капитала. Большие raw archives и торговые credentials не включены.

Все runtime authority-флаги false. NoTrade остаётся default допуска. Ни Git push, ни выбор исследовательского кандидата не дают модели permission на orders, paper/live или promotion.
