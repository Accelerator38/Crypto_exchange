# Genetic Primus: исторический research snapshot

Дата публикации: 28 августа 2026. **Не допущен к торговле. Incumbent остаётся NoTrade.**

## Что выбрано

В `model.json` сохранён неизменённый GA-кандидат `f7a4ae11f8db1bc7ed31bfc2ecf33f3fcfb5163a59b81b1fa142ee24fda6413e` из второго origin measurement lab v2. Это лучший наблюдавшийся validation-PnL среди выбранных генетических кандидатов этого зафиксированного сравнения, а не доказанно лучшая стратегия или рекомендация для реальных денег. Выбор для архива сделан после просмотра validation; это окно нельзя считать новым независимым holdout.

Модель — linear binary overlay над V7 EMA TrendConsensus: четыре входа, пять коэффициентных позиций с bias, два ненулевых feature weights. Геном `[0, 0, 1, 1, -1]`; scaler обучен только на train. Overlay разрешает базовый сигнал при положительном logit; отсутствующие признаки означают abstention. Полный объект модели, scaler и его исходный SHA сохранены без переобучения.

## Ограничения

- Train: 04.08.2024 16:00 — 01.01.2025 16:00 UTC. Это **устаревший исторический snapshot**, не модель на актуальном cutoff августа 2026.
- Frozen review переоценил статистику, не обучал модель. Нормальный и stress HAC LCB отрицательны. Калибровка HAC на synthetic audit не является проверкой торговой прибыльности.
- Полный цикл переобучения каждые три дня и устойчивое преимущество на новом длинном outer interval этим snapshot не доказаны.
- Shorts синтетические; funding, borrow, latency и другие execution-риски не квалифицированы для live.
- Архив содержит параметры и provenance, **не самостоятельный торговый пакет**. Исходные датасеты, большие decision ledgers и весь экспериментальный код в эту публикацию не включены. Хеши позволяют сверить их в исходной рабочей среде, но не заменяют сами файлы для полного воспроизведения.

## Проверка целостности

`model_sha256` — SHA-256 UTF-8 сериализации поля `model` через `json.dumps(model, sort_keys=True, separators=(',', ':'), allow_nan=False)`. SHA целого файла отличается от SHA объекта модели. Snapshot сохраняет bounds, scaler fit hash, dataset hash, train/validation resample hashes и хеши исходных конфигураций/кода. Проверка экспорта сверяет их с frozen local artifacts; не запускает обучение, collector, pytest или сеть биржи.
