# Причинный план labels: timestamps и purge

Дата: 2026-10-07. Статус: код и воспроизводимость проверены; ценовые labels не рассчитаны.

## Прогресс

Новый чистый helper подключён к metadata завершённого этапа признаков. Зарегистрированный ingestion lag 0 сохранён. Execution delay остаётся None: доступность полного бара сразу после закрытия не доказывает мгновенное вычисление или исполнение сделки.

Реализованы следующие правила:

- decision readiness = decision as-of + отдельно заданная execution delay;
- entry — первый 4h open строго после readiness, в том числе при delay 0;
- exit — entry + 18 баров, то есть ровно три дня удержания;
- availability label — закрытие полной выходной строки + ingestion lag;
- допуск в training — availability label не позже training as-of минус 7 баров purge;
- исходная 18-барная сетка кандидатов не расширяется; исключения сохраняются с причиной;
- training-prefix и deployment context не становятся обучающими samples.

Следующий open является reference price, а не подтверждённым исполнимым fill. Этот план сам не разрешает чтение цен, fit, финансовый анализ или торговлю.

## Проверки

Успешно выполнены py_compile отдельных новых файлов, прямой вызов чистой функции на вымышленном clock, `--check` и `--verify`.

Проверены строгий следующий open, сохранение 18-барного горизонта, точная граница purge и сдвиг на 1 мс, ненулевой ingestion lag, сдвиг entry при задержке в один бар, coverage boundary, отказ от отрицательной/нецелой/bool/невыбранной задержки в прямом расчёте, несоответствия frozen clock и дубликатов events. Без выбранного сценария общий план остаётся закрытым.

Receipt предыдущего этапа проверен до и после расчёта расписания без повторного чтения parquet. Числовые значения признаков/checkpoints не разбирались; производные файлы проверялись по bytes/SHA. Закреплены 202 metadata/source identities. Frozen validators и предыдущие артефакты не изменялись.

При разработке обнаружены и исправлены две локальные ошибки интеграции: имена coverage fields и смешение semantic JSON SHA с SHA сериализованных bytes. До их исправления checks завершались ошибкой, результаты нового этапа не публиковались. Итоговый receipt воспроизводится.

## Только гипотетический сценарий delay 0

В существующей сетке 572 candidate events. Из них 571 проходит maturity/purge, один поздний кандидат исключён. Два контекстных события исключены из training по роли. Для восьми символов это план 4 568 допустимых sample slots, ещё не X/y и не наблюдаемые целевые значения.

Это проверка расписания, не выбор пользователем сценария исполнения. Сценарий пока не зарегистрирован; значения доходности не вычислялись.

Parquet reads в этом этапе: 0. Label values: 0. Fit: 0. Все девять safety-разрешений false. Collector, сеть, runtime, бумажные/реальные ордера не запускались. Исторический период не становится prospective.

## Следующий шаг

После явного выбора инженерного сценария исполнения можно материализовать исторические targets с source SHA до/после чтения и lineage входной/выходной строки каждого sample. Все исходы, включая нулевые и отрицательные, должны сохраняться. Deployment labels не входят в training.

Для обучения всё ещё нужны согласованные costs/reference-price bridge и net objective. Gross open/open label нельзя молча считать net return или доказательством превосходства над NoTrade. Допуск к реальным деньгам не рассматривается.
