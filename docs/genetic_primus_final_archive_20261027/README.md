В ветке находятся исходники, конфигурации, тестовые сценарии и читаемые отчёты. В ZIP релиза — также сохранённые модели, предсказания и расчётные артефакты. Файлы ZIP содержат собственный `ARCHIVE_CONTENT_MANIFEST.json`: размер и SHA-256 каждого файла, Python и версии библиотек. Это архив исследований с несколькими историческими схемами расчёта, а не единый installer.

Полная локальная копия дополнительно содержит исследовательские данные и доступные локальные версии отслеживаемых файлов проекта. Она расположена в `Archives/genetic_primus_final_20261027/`. Локальный manifest указывает каждый сохранённый путь. Внешние файлы из Downloads, все произвольные `outputs/`, `.env` и действующие virtual environments в объём полного исследовательского архива не входят. Исходное рабочее дерево оставлено на прежней ветке.

Восстановление: сначала проверить SHA-256 ZIP по release metadata, затем member hashes по вложенному manifest. Для воспроизведения конкретного эксперимента читать его registration, environment и amendment, использовать соответствующие данные и версию scorer. Для последней regularization-проверки нужен **scoring v2**: v1 сохранился как историческая ошибочная попытка. Наличие старого launcher в архиве не означает разрешение запускать сеть или торговлю.

Новый prospective-интервал не запечатан и не запущен. Старые файлы с DRAFT и предложенными датами остаются историческими черновиками. Все планы статей — предложения для отдельного возобновления исследований.
