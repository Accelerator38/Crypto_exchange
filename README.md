# Crypto Exchange / Panteon

Исследовательская платформа для симуляции, ретротестов и экспериментального исполнения торговых стратегий на криптобиржах. В репозитории есть агентный runtime, контуры paper/demo, исследовательские наборы данных, отчёты и тесты. Публикация ориентирована на изучение архитектуры и воспроизведение доступных проверок.

## С чего начать

- `src/panteon_v2/` — текущие компоненты исполнения, политики и тесты.
- `src/panteon_runtime/` — инфраструктура и исторические агенты.
- `configs/strategy_candidates_v1.json` и `configs/strategy_experiment_registry_v1.json` — контракты и реестр исследовательских гипотез.
- `docs/PANTEON_3_OPERATOR_GUIDE.md` — актуальное состояние допуска и правила запуска.
- `docs/PANTEON_VNEXT_STRATEGY.md` — требования к доказательствам стратегии.
- `evidence/` и `Reports/` — опубликованная часть исследовательских материалов.

## Быстрая проверка без ключей и сети

Нужен Python 3.11+ с зависимостями из `requirements.txt`. В активированном виртуальном окружении:

```bash
python -m pip install -r requirements.txt
python tools/check_strategy_candidates.py
python tools/check_strategy_experiment_registry.py --metadata-only
python -m pytest src/panteon_v2/tests/test_experiment_registry.py -q
```

`--metadata-only` проверяет схему реестра и запретительные флаги; результат явно помечен как **непроверенная целостность артефактов**. Полная команда без этого флага сверяет SHA-256 каждого зарегистрированного файла и должна завершиться ошибкой, если файл отсутствует. Часть исходных артефактов не опубликована, поэтому полный прогон из публичного клона невозможен. Это не снимает проверку целостности с рабочего контура.

## Статус

Текущий реестр не содержит operational candidate, ордера отключены, а опубликованные гипотезы отклонены либо заблокированы отсутствием данных. Код не следует запускать с реальными ключами по одному только README. Актуальное решение о допуске всегда содержится в [операторском руководстве](docs/PANTEON_3_OPERATOR_GUIDE.md) и проверяется отдельными gate процедурами. `.env.example` показывает имена переменных; ключи и локальный `.env` не входят в Git.
